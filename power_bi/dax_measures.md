# Enterprise DAX Measures Library for Power BI

This document contains production-ready Data Analysis Expressions (DAX) measures developed for the E-Commerce Sales & Customer Analytics model.

---

## 1. Core Transactional KPIs

### Total Revenue
Calculates net sales revenue taking volume, unit price, and discount percentage into account.
```dax
Total Revenue = 
SUM(fact_sales[revenue])
```
*Format: Currency (`$#,##0.00`)*

### Total Orders
Distinct count of unique order identifiers.
```dax
Total Orders = 
DISTINCTCOUNT(fact_sales[order_id])
```
*Format: Whole Number (`#,##0`)*

### Total Units Sold
Aggregated volume of individual units purchased across all orders.
```dax
Total Units Sold = 
SUM(fact_sales[quantity])
```
*Format: Whole Number (`#,##0`)*

### Average Order Value (AOV)
Key profitability indicator measuring average revenue captured per distinct order.
```dax
Average Order Value = 
DIVIDE([Total Revenue], [Total Orders], 0)
```
*Format: Currency (`$#,##0.00`)*

### Average Units Per Order (Basket Size)
```dax
Units Per Order = 
DIVIDE([Total Units Sold], [Total Orders], 0)
```
*Format: Decimal (`0.0`)*

### Average Discount Rate %
```dax
Average Discount Pct = 
AVERAGE(fact_sales[discount])
```
*Format: Percentage (`0.0%`)*

## 2. Time-Intelligence & Growth Measures

### Revenue Prior Month (PM)
```dax
Revenue Prior Month = 
CALCULATE(
    [Total Revenue],
    DATEADD(dim_dates[date_key], -1, MONTH)
)
```

### Month-over-Month (MoM) Revenue Growth ($)
```dax
MoM Revenue Growth $ = 
[Total Revenue] - [Revenue Prior Month]
```

### Month-over-Month (MoM) Revenue Growth %
```dax
MoM Revenue Growth % = 
VAR PrevRev = [Revenue Prior Month]
RETURN
    IF(
        ISBLANK(PrevRev),
        BLANK(),
        DIVIDE([Total Revenue] - PrevRev, PrevRev, 0)
    )
```
*Format: Percentage with dynamic color KPI formatting (`+0.0%; -0.0%; 0.0%`)*

### Revenue Year-to-Date (YTD)
```dax
Revenue YTD = 
TOTALYTD([Total Revenue], dim_dates[date_key])
```

### Revenue Same Period Last Year (SPLY / PY)
```dax
Revenue Prior Year = 
CALCULATE(
    [Total Revenue],
    SAMEPERIODLASTYEAR(dim_dates[date_key])
)
```

### Year-over-Year (YoY) Revenue Growth %
```dax
YoY Revenue Growth % = 
VAR PriorYear = [Revenue Prior Year]
RETURN
    DIVIDE([Total Revenue] - PriorYear, PriorYear, 0)
```
*Format: Percentage (`0.0%`)*

## 3. Customer Intelligence & Retention Measures

### Total Active Customers
Distinct count of unique customers transacting within the filtered context.
```dax
Active Customers = 
DISTINCTCOUNT(fact_sales[customer_id])
```

### Repeat Customers Count
Number of unique customers who have completed more than 1 distinct order.
```dax
Repeat Customers Count = 
CALCULATE(
    DISTINCTCOUNT(dim_customers[customer_id]),
    dim_customers[customer_type] = "Repeat"
)
```

### Repeat Customer Rate %
The proportion of active customer base demonstrating multi-purchase loyalty.
```dax
Repeat Customer Rate % = 
DIVIDE([Repeat Customers Count], [Active Customers], 0)
```
*Format: Percentage (`0.0%`)*

### Repeat Customer Revenue Share %
Revenue generated by repeat customers divided by total business revenue.
```dax
Repeat Customer Revenue Share % = 
CALCULATE(
    [Total Revenue],
    dim_customers[customer_type] = "Repeat"
) / [Total Revenue]
```
*Format: Percentage (`0.0%`)*

### Customer Lifetime Value (CLV)
```dax
Average Customer Lifetime Value = 
DIVIDE([Total Revenue], DISTINCTCOUNT(dim_customers[customer_id]), 0)
```
*Format: Currency (`$#,##0.00`)*

## 4. Product & Category Performance Measures

### Category Share of Total Revenue %
Calculates the proportion of sales from each category against unfiltered company revenue.
```dax
Category Revenue Share % = 
DIVIDE(
    [Total Revenue],
    CALCULATE([Total Revenue], ALL(dim_products[category])),
    0
)
```
*Format: Percentage (`0.0%`)*

### Top 5 Products Revenue Contribution %
```dax
Top 5 Products Revenue = 
CALCULATE(
    [Total Revenue],
    TOPN(5, ALL(dim_products[product_name]), [Total Revenue], DESC)
)
```

### Product Pareto Cumulative Revenue %
Used to plot the 80/20 Pareto curve in Power BI line & clustered column charts.
```dax
Pareto Cumulative Revenue % = 
VAR CurrentProductRevenue = [Total Revenue]
VAR CurrentProduct = SELECTEDVALUE(dim_products[product_name])
VAR AllProductsRanked = 
    ADDCOLUMNS(
        ALL(dim_products[product_name]),
        "@ProdRev", [Total Revenue]
    )
VAR RunningTotal = 
    SUMX(
        FILTER(AllProductsRanked, [@ProdRev] >= CurrentProductRevenue),
        [@ProdRev]
    )
RETURN
    DIVIDE(RunningTotal, CALCULATE([Total Revenue], ALL(dim_products)), 0)
```

## 5. Regional & Geographic Performance Measures

### Regional Revenue Share %
```dax
Regional Revenue Share % = 
DIVIDE(
    [Total Revenue],
    CALCULATE([Total Revenue], ALL(dim_regions[region])),
    0
)
```

### Regional Sales Target Achievement
Compares actual regional sales against target quota.
```dax
Regional Target Achievement % = 
VAR RegionalActual = [Total Revenue]
VAR TargetRate = VALUE(SUBSTITUTE(SELECTEDVALUE(dim_regions[target_growth_rate], "15%"), "%", "")) / 100
VAR BaselineExpected = 375000 * (1 + TargetRate)
RETURN
    DIVIDE(RegionalActual, BaselineExpected, 0)
```
